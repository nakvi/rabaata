# Visual system

Warm civic editorial style. Ivory canvas #f8f7f2, deep green ink #163d35, muted sage surfaces, restrained brass accents. Manrope headings and DM Sans text with system fallbacks. Fonts are loaded from Google Fonts; self-host licensed font files if network-independent fonts are required.

Use clear text hierarchy, generous spacing and thin borders. Homepage uses a decorative CSS perspective illustration, visible search, task categories and region list. The illustration is symbolic and must not be presented as a geographic map. Directory prioritizes legibility, source honesty and fast controls. Avoid gradients on text, excessive movement and fake official seals.

Cards rise slightly on hover. Respect prefers-reduced-motion. Keep form labels visible, keyboard focus clear, controls labelled, and result counts announced. At narrow widths filters move above results and navigation collapses. Preparation guides have print CSS.

## V2

Jade gradient hero, dimensional off-white favicon tiles, thicker raised card surfaces, 14 task categories, keyword chips, pagination. Resource logos load remotely with a category fallback; do not invent official seals. Maintain source transparency.

## V3

A low-opacity, locally bundled Pakistan flag watermark sits behind content. Custom crescent/star favicon and touch icon. English, Urdu (RTL) and Roman Urdu layouts; Arabic-script headings use Noto Naskh Arabic with system fallbacks. Theme controls support light, dark and system. Browser-local preferences persist. Dark surfaces use green-neutral tones with pale sage controls and high-contrast text. The directory keeps task controls usable above decorative effects.
